# Toll_Plaza_Traffic_Pridiction

Project Overview

This project explores the application of Machine Learning techniques to analyse and predict traffic patterns at toll plazas.

The objective is to use historical traffic data to identify patterns, understand traffic behaviour and develop predictive models that can support traffic management and operational planning.

Objectives

* Analyse historical toll plaza traffic data.
* Perform data cleaning and preprocessing.
* Identify relevant features influencing traffic patterns.
* Develop and train machine learning models.
* Evaluate model performance using appropriate evaluation metrics.
